# Introduction: Evaluating Complex AI Systems

- Previous lessons covered systems shaped like a single "input → output" pair, e.g. summarization or simple question-answering. [`0:01`](https://www.youtube.com/watch?v=6EtqsMcEhaw&t=1)
- Many real AI applications are more complex than that — agents and chatbots — so a single input/output check is not enough. [`0:01`](https://www.youtube.com/watch?v=6EtqsMcEhaw&t=1)
- This video presents a few general principles for evaluating these more complex systems. [`0:17`](https://www.youtube.com/watch?v=6EtqsMcEhaw&t=17)

The three principles the video develops:

1. Break the system down into smaller testable components. [`1:46`](https://www.youtube.com/watch?v=6EtqsMcEhaw&t=106)
2. Test only the final outcome, treating the system as a black box. [`4:21`](https://www.youtube.com/watch?v=6EtqsMcEhaw&t=261)
3. Test the complete interaction (manually, programmatically, and online). [`4:44`](https://www.youtube.com/watch?v=6EtqsMcEhaw&t=284)
