# Generative quality metrics (BLEU / ROUGE)

## What they are

- Require ground truth; described as "less useful but still worth a mention" [`1:36`](https://www.youtube.com/watch?v=6eOcgYP5D4Q&t=96)
- Metrics like **BLEU** and **ROUGE**, originally designed for translation and summarization [`1:36`](https://www.youtube.com/watch?v=6eOcgYP5D4Q&t=96)
- Work by comparing generated text to an ideal reference text (ideal summary/translation) and measuring word/symbol overlap, in a few more complicated ways [`1:36`](https://www.youtube.com/watch?v=6eOcgYP5D4Q&t=96)

## Limitation

- Useful in some scenarios, but overlap in symbols is often not very meaningful as a quality signal [`1:58`](https://www.youtube.com/watch?v=6eOcgYP5D4Q&t=118)
