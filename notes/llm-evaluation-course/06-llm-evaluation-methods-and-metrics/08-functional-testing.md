# Functional testing

- Checks whether the LLM output **actually works** for its specific task [`4:02`](https://www.youtube.com/watch?v=6eOcgYP5D4Q&t=242)
- Example: if the LLM generates SQL queries or Python code, test that the code is valid — and possibly even run it in a sandbox [`4:02`](https://www.youtube.com/watch?v=6eOcgYP5D4Q&t=242)
