# ML-based evaluators

- You don't always need an LLM to evaluate — smaller ML models can check specific properties: **sentiment, toxicity, emotion** [`3:21`](https://www.youtube.com/watch?v=6eOcgYP5D4Q&t=201)
- Characteristics: lightweight, **no ground truth required**, often available off-the-shelf [`3:21`](https://www.youtube.com/watch?v=6eOcgYP5D4Q&t=201)
- Example: run a sentiment analysis model to flag responses that are overly negative [`3:21`](https://www.youtube.com/watch?v=6eOcgYP5D4Q&t=201)
