# Real-world examples of LLM-powered products

## Company examples

All cited at [`2:21`](https://www.youtube.com/watch?v=B7fl6He1lxM&t=141):

| Company | LLM use case |
|---|---|
| StitchFix, NextDoor | Create marketing texts |
| Salesforce | Summarize Slack conversations |
| Vimeo | Summarize videos |
| Google, Incident.io | Summarize security incidents |
| Dropbox | Ask questions about files |
| DoorDash | LLM-based support chatbot |

## Bridge to evaluation

- Once you build a similar LLM-powered product or feature, two questions inevitably arise: *Is it working as expected?* and *What can I do to improve it?* [`2:42`](https://www.youtube.com/watch?v=B7fl6He1lxM&t=162).
- That is when you start caring about **evaluation** — "evals", as the community calls it — the topic of the next videos in the series [`2:42`](https://www.youtube.com/watch?v=B7fl6He1lxM&t=162).
