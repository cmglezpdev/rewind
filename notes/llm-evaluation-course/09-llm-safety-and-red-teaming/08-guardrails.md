# Second line of defense: guardrails

- **Definition**: real-time checks that verify what goes into and comes out of the app. [`3:49`](https://www.youtube.com/watch?v=XZZ6glt0AMA&t=229)
- **Input side**: screen user queries — e.g., block a query that contains sensitive information. [`3:49`](https://www.youtube.com/watch?v=XZZ6glt0AMA&t=229)
- **Output side**: screen model responses — e.g., detect that an output resembles financial advice and block it. [`4:05`](https://www.youtube.com/watch?v=XZZ6glt0AMA&t=245)
- **Limitation**: guardrails add latency, so you cannot run a check for every imaginable case — they are useful but not perfect. [`4:05`](https://www.youtube.com/watch?v=XZZ6glt0AMA&t=245)
