# What is LLM product quality

LLM testing usually comes down to two things [`1:16`](https://www.youtube.com/watch?v=RIGU1hy3UR8&t=76):

1. **Capabilities** — the app does what it's supposed to; responses are accurate, useful, helpful. The definition of "good" depends on the use case [`1:16`](https://www.youtube.com/watch?v=RIGU1hy3UR8&t=76).
2. **Risks** — the outputs are safe and the system doesn't generate anything harmful [`1:16`](https://www.youtube.com/watch?v=RIGU1hy3UR8&t=76).
