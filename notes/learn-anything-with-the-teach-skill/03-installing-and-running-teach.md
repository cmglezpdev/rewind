# 3. Installing and running `teach`

## Install

1. Go to the skills repo (Matt Pocock's skills repo) ([`2:20`](https://www.youtube.com/watch?v=s5T5oQJcJ6U&t=140)).
2. Find the **Quick Start** section ([`2:20`](https://www.youtube.com/watch?v=s5T5oQJcJ6U&t=140)).
3. Run the `skills.sh` installer and select the **Teach** skill ([`2:20`](https://www.youtube.com/watch?v=s5T5oQJcJ6U&t=140)).

## Run

- Move to an **empty directory** — that directory becomes the teaching workspace ([`2:20`](https://www.youtube.com/watch?v=s5T5oQJcJ6U&t=140)).
- Invoke `teach` inside your coding agent with the goal stated in plain language, e.g. *"Teach me how to solve a Rubik's Cube"* ([`2:20`](https://www.youtube.com/watch?v=s5T5oQJcJ6U&t=140)).
- Over the course of a learning journey the skill accumulates a noticeable number of files in that directory — the visible evidence that the skill is stateful ([`2:20`](https://www.youtube.com/watch?v=s5T5oQJcJ6U&t=140)).

## Model used in the demo

- **Opus 4.8 with medium effort** ([`7:00`](https://www.youtube.com/watch?v=s5T5oQJcJ6U&t=420)).
