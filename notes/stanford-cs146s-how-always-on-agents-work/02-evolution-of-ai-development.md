# The evolution of AI development

## Four eras in Lee's account

1. Copy code from ChatGPT into an editor. [`2:34`](https://www.youtube.com/watch?v=L1OBRtfPS34&t=154)
2. Use terminal agents that edit files and run shell commands. [`3:03`](https://www.youtube.com/watch?v=L1OBRtfPS34&t=183)
3. Run coding agents through dedicated apps, sometimes in parallel or in the cloud. Reviewing every command still makes the human a bottleneck. [`3:22`](https://www.youtube.com/watch?v=L1OBRtfPS34&t=202)
4. Use ambient agents with their own computers, memory, and reusable skills that keep working while the user is away. [`3:44`](https://www.youtube.com/watch?v=L1OBRtfPS34&t=224)

## Interaction changes

- Steering replaces a strict prompt-wait cycle. A user can ask the agent to check a thread, then immediately add that it should happen Thursday; the model and harness must interpret the second message as a correction to the same task. [`4:08`](https://www.youtube.com/watch?v=L1OBRtfPS34&t=248) [`4:29`](https://www.youtube.com/watch?v=L1OBRtfPS34&t=269) [`4:53`](https://www.youtube.com/watch?v=L1OBRtfPS34&t=293)
- Auto review uses a separate model to check commands. Lee argues that this can outperform humans fatigued by repeated approval prompts, but gives no benchmark or numerical result in this passage. [`4:53`](https://www.youtube.com/watch?v=L1OBRtfPS34&t=293) [`5:20`](https://www.youtube.com/watch?v=L1OBRtfPS34&t=320)
- The product becomes a familiar texting interface for delegating real work, rather than only a question-answering interface. [`5:38`](https://www.youtube.com/watch?v=L1OBRtfPS34&t=338) [`6:05`](https://www.youtube.com/watch?v=L1OBRtfPS34&t=365)
