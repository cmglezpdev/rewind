# Learn with agents and primary sources

## Treat explanations as a starting point

- When Herk asks whether to trust what an agent teaches, Pocock recommends skepticism and reading the primary source himself. [`6:55`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=415) [`7:24`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=444)
- His Teach skill fetches high-trust primary sources and explains them with quotations, attribution, and links, giving the learner a way to inspect the evidence. [`7:39`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=459)
- Pocock says hallucinations have become less frequent in his experience, but still occur. His workflow is to use a teaching session to learn the topic's language, then read the original material for the information he needs. [`8:00`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=480)

## A reusable learning sequence

1. Ask the agent to introduce an unfamiliar topic through high-quality primary sources and linked explanations. [`7:39`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=459)
2. Use that explanation to build enough vocabulary to understand the original source. [`8:00`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=480)
3. Read the primary source yourself before relying on the explanation. [`7:24`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=444) [`8:00`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=480)
