# Matt Pocock: The Most Valuable Skill to Learn in the Age of AI

![Video cover](./cover.webp)

In this interview, Matt Pocock and Nate Herk discuss how to communicate intent to AI agents, improve the codebases they work in, and develop trust through observable results. Pocock describes a failed spec-driven workflow, the value of shared domain language, and opportunities in adapting agents to organizational knowledge work. The discussion offers personal experience and recommendations rather than controlled benchmarks. ## Key takeaways

- Explicit priorities remain necessary as models improve. Pocock argues that agents cannot infer what you care about, so skills and other processes must communicate it. [`29:44`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=1784) [`30:07`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=1807)
- A maintainable codebase is part of the agent's working environment. After months of deteriorating results with a large-spec workflow, Pocock returned his focus to code that was easy to change and reported renewed progress. [`28:02`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=1682) [`28:22`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=1702) [`28:46`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=1726) [`29:08`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=1748)
- Questioning reveals missing requirements. Grill Me interviews the builder to expose priorities and concerns such as security and deployment before the agent fills the gaps itself. [`17:01`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=1021) [`17:34`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=1054)
- Shared product vocabulary reduces ambiguity. Pocock recommends using the same meaning for an order in client conversations, code, the database, and the UI. [`24:03`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=1443) [`24:23`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=1463)
- Better application access improved his agent's work. Enabling browser interaction, screenshots, and a functioning local application gave the agent better evidence and, in his account, substantially improved quality. [`33:29`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=2009)
- Reusable knowledge-work processes are a career opportunity in Pocock's view because verification is difficult and each organization works differently. [`13:30`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=810) [`14:07`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=847)
- Start with boring, inspectable tasks and earn trust gradually. Pocock favors work with measurable outputs and easy corrections, while keeping humans involved as agent use expands. [`37:54`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=2274) [`38:09`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=2289) [`40:04`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=2404) [`41:03`](https://www.youtube.com/watch?v=Z8lf5oWKfj0&t=2463)
