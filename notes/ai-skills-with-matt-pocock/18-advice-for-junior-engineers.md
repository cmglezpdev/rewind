# Advice for junior engineers

- Matt says he would love to be a junior engineer now because agents make it easier to build useful tools while learning. [`1:28:36`](https://www.youtube.com/watch?v=4DhcSPkEbwI&t=5316)
- He recommends using agents heavily because that is how many developers will work going forward. [`1:29:06`](https://www.youtube.com/watch?v=4DhcSPkEbwI&t=5346)
- Grill Me helps juniors by simulating discussion with a senior developer and keeping them close to deeper design questions. [`1:29:31`](https://www.youtube.com/watch?v=4DhcSPkEbwI&t=5371)
- Agents would have helped his early spectrogram tool by identifying performance problems such as six nested loops and a 10 FPS frame rate. [`1:30:00`](https://www.youtube.com/watch?v=4DhcSPkEbwI&t=5400)
- Matt says the best opportunity belongs to people interested in the process of creating code, not only the code itself. [`1:30:24`](https://www.youtube.com/watch?v=4DhcSPkEbwI&t=5424)
- He sees curiosity, adaptability, interest in better software, and attention to personal process as the traits helping engineers thrive with AI. [`1:30:49`](https://www.youtube.com/watch?v=4DhcSPkEbwI&t=5449)
