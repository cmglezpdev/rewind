# Sponsor segment: code review and shared knowledge

These are promotional claims from the Graptile sponsor segment, not an independent evaluation. [`1:11`](https://www.youtube.com/watch?v=y5TEATUDDfc&t=71)

- T-Rex lets review agents run proposed code in a sandbox to check whether changes work. [`1:30`](https://www.youtube.com/watch?v=y5TEATUDDfc&t=90)
- The editable knowledge base updates as the codebase changes. MCP access exposes that knowledge to coding agents. [`1:30`](https://www.youtube.com/watch?v=y5TEATUDDfc&t=90) [`1:51`](https://www.youtube.com/watch?v=y5TEATUDDfc&t=111)
- Three review tiers let users vary review effort and credit spend. Theo describes the base tier as cheaper and Apex as suited to thorough reviews of PRs touching 20-plus files. [`1:51`](https://www.youtube.com/watch?v=y5TEATUDDfc&t=111) [`2:11`](https://www.youtube.com/watch?v=y5TEATUDDfc&t=131)
