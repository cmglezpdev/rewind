# Token prices versus cost per task

## Three ways to compare price

1. Token prices depend on input, output, and caching. A lower list price per token does not establish a cheaper completed task. [`6:05`](https://www.youtube.com/watch?v=Hq2c7pww1Ds&t=365)
2. Task cost also depends on how many tokens the model needs to solve the problem. Different reasoning settings can change that consumption. [`6:05`](https://www.youtube.com/watch?v=Hq2c7pww1Ds&t=365) [`6:28`](https://www.youtube.com/watch?v=Hq2c7pww1Ds&t=388)
3. Subscription cost per task additionally depends on the effective allowance or discount supplied by the plan. This can change the API-price ranking. [`7:34`](https://www.youtube.com/watch?v=Hq2c7pww1Ds&t=454)
