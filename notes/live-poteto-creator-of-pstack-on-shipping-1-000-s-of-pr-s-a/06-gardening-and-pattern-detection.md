# 6. Gardening, queues, and finding patterns

- The 2,500 PRs were not 2,500 features. Much of the work was "gardening": ongoing cleanup and improvement, including work agents identify by reading the code. [`45:26`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=2726) [`45:54`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=2754)
- One routine scans React code for banned patterns but records findings in a document rather than fixing them immediately. Poteto reviews the accumulated list every few days to see whether several findings point to the same underlying issue. [`47:24`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=2844) [`47:55`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=2875)
- A buffer or queue can preserve a human review point and make repeated patterns visible. Immediate execution on every finding can keep agents busy while hiding the bigger problem. [`47:55`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=2875) [`48:24`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=2904)
- A coordinator can help see the broader pattern across multiple tasks while still directing implementation work. [`48:51`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=2931)
