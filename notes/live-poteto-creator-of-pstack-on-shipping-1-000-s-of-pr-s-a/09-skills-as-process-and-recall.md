# 9. Skills as process, and learning from transcripts

- Poteto views skills as processes expressed in language. He encourages combining skills from different sources and adapting them to the user's own tools and work habits. [`59:49`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=3589) [`1:00:48`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=3648) [`1:01:15`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=3675)
- Past agent transcripts contain the real process: corrections, repeated interventions, and context that would otherwise be lost. Reviewing them can reveal lessons to turn into skills or lint rules. [`1:02:19`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=3739) [`1:02:51`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=3771)
- Poteto created a Pstack skill called `recall` after repeatedly needing to bring useful context from prior chats into new work on Cursor virtualization. The skill compresses the transcript review workflow so he does not have to restate it each time. [`1:03:10`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=3790) [`1:03:31`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=3811)
- He expects skills to become shorter as models improve. The durable value is the workflow and sequence of decisions, while detailed implementation instructions may become unnecessary. [`1:03:56`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=3836) [`1:04:13`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=3853)
- Each person's tools and skills will differ. The recommended starting point is to inspect one's own transcripts, identify repeated interventions, and turn them into reusable workflows or constraints. [`1:01:33`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=3693) [`1:02:19`](https://www.youtube.com/watch?v=MN9dGgmLyso&t=3739)
