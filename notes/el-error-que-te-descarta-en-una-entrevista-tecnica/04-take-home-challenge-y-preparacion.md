# Take-home challenge y preparación según el puesto

## Qué se evalúa en un take-home

Cumplir la función solicitada es solo una parte. Una entrega sólida permite revisar:

- uso de Git y organización del proyecto; [`8:21`](https://www.youtube.com/watch?v=rkm5mAymtg4&t=501)
- backend, frontend y despliegue cuando correspondan; [`8:21`](https://www.youtube.com/watch?v=rkm5mAymtg4&t=501)
- cumplimiento completo de la consigna y buenas prácticas; [`8:21`](https://www.youtube.com/watch?v=rkm5mAymtg4&t=501)
- documentación, pruebas unitarias y pruebas de integración. [`8:21`](https://www.youtube.com/watch?v=rkm5mAymtg4&t=501)

Entregar únicamente el requisito mínimo impide mostrar estas capacidades. [`8:21`](https://www.youtube.com/watch?v=rkm5mAymtg4&t=501)

## Pruebas y dependencias

- Las pruebas no deberían depender siempre de una API real en ejecución. Usar todas las dependencias reales muestra una comprensión débil del aislamiento que busca un test. [`8:57`](https://www.youtube.com/watch?v=rkm5mAymtg4&t=537)
- Conviene saber cuándo usar dobles de prueba, pruebas unitarias y pruebas de integración, y poder explicar esa elección. [`8:57`](https://www.youtube.com/watch?v=rkm5mAymtg4&t=537)

## La exigencia cambia

- El formato y la dificultad dependen del seniority, la empresa y la compensación. [`9:20`](https://www.youtube.com/watch?v=rkm5mAymtg4&t=560)
- Un perfil junior probablemente reciba menos preguntas complejas de arquitectura. Para un perfil senior son más probables arquitectura, paralelismo y concurrencia. [`9:20`](https://www.youtube.com/watch?v=rkm5mAymtg4&t=560)
- Las empresas estadounidenses con sueldos altos pueden aplicar procesos más exigentes. El video menciona rangos de 8.000 a 10.000 dólares mensuales al comparar niveles de complejidad. [`9:20`](https://www.youtube.com/watch?v=rkm5mAymtg4&t=560) [`9:45`](https://www.youtube.com/watch?v=rkm5mAymtg4&t=585)
