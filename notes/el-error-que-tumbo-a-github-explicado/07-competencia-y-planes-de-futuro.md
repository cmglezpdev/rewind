# 07 · Competencia, planes de futuro y cierre

## Competencia

- GitHub está perdiendo la confianza de los desarrolladores en la era de la programación con IA, y la competencia no se queda quieta [`14:39`](https://www.youtube.com/watch?v=h5of8RrGLeE&t=879)
- Durante la caída, **Cursor presentó oficialmente Origin**, su sistema de repositorios «para la era agéntica»; el autor no sabe si fue planificado o aprovecharon el ruido, pero lo considera una muy buena jugada de marketing [`15:07`](https://www.youtube.com/watch?v=h5of8RrGLeE&t=907)

## Reflexión de fondo

- Los repositorios de código se concibieron asumiendo que los humanos escribirían y ejecutarían el código; esa premisa cambió y adaptar infraestructura no es tan rápido como nos gustaría [`15:50`](https://www.youtube.com/watch?v=h5of8RrGLeE&t=950)

## Planes anunciados por GitHub

- Redundancia de servidores, mejor monitorización, capacidad de cambio entre regiones sin que caiga para todos, y aumentar la capacidad de los balanceadores de carga [`16:20`](https://www.youtube.com/watch?v=h5of8RrGLeE&t=980)

## Cierre

- Leer postmortems como este (de GitHub y otras plataformas) es una de las mejores formas de aprender: entender los problemas de raíz siempre aporta valor [`16:53`](https://www.youtube.com/watch?v=h5of8RrGLeE&t=1013)
