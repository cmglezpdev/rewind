# What agents already do well

- Mantinband says agents are extremely good at writing code in any language, including unfamiliar or newly invented languages when given a clear brief. [`1:49`](https://www.youtube.com/watch?v=SCXhmMbbh6g&t=109)
- He says recent models have changed his view: over the past several months, Opus 4.6 and 4.7 have produced production-ready output on complex codebases for him. [`1:49`](https://www.youtube.com/watch?v=SCXhmMbbh6g&t=109)
- He argues it is naive to assume agents will not outperform human developers in output quality. [`2:27`](https://www.youtube.com/watch?v=SCXhmMbbh6g&t=147)
- Agents are also strong at taking a direction, planning the implementation in detail, and then executing it. [`2:27`](https://www.youtube.com/watch?v=SCXhmMbbh6g&t=147)
- His practical conclusion is that writing code by hand is no longer a good use of developer time when an agent can produce the code and the human can review or guide it. [`2:27`](https://www.youtube.com/watch?v=SCXhmMbbh6g&t=147) [`2:58`](https://www.youtube.com/watch?v=SCXhmMbbh6g&t=178)
- Agents work especially well inside known frameworks and solved problem spaces. [`5:45`](https://www.youtube.com/watch?v=SCXhmMbbh6g&t=345)
- He believes agents are approaching the point where reading every generated line of code will become obsolete, with tests and high-level validation replacing line-by-line review. [`6:19`](https://www.youtube.com/watch?v=SCXhmMbbh6g&t=379) [`6:54`](https://www.youtube.com/watch?v=SCXhmMbbh6g&t=414)
